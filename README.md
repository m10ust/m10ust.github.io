# m10ust.github.io

Homepage hub for the m10ust GitHub Pages root site, live at **https://m10ust.github.io/**.

## Purpose

Single-page directory linking the public m10ust projects (nethtop, machscope, the Model Index).
A hub, not a trophy wall — the receipts live in the repos themselves.

## Ownership & workflow

- **Single human owner:** Sebastien Miousse (m10ust).
- **Sole pusher:** Oracle (the Mac Mini Hermes instance). No other agent pushes here.
- **Content rules:** static only (HTML/CSS/assets). No secrets, no logs, no private-repo links.
- **Update flow:** edit `index.html` → commit → push to `main` → GitHub Pages serves the root.

## Site map

- `/` — this hub
- `/model-index/` — the M4YOU Model Index (separate repo `m10ust/model-index`)
